# Mfunda Portfolio

Vue 3 portfolio app powered by Vite.

The app uses Vue Router with page views in `src/views`, shared navigation and footer components in `src/components`, and the portfolio styles in `src/assets/portfoliostyle.css`.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production bundle, run:

```bash
npm run build
```
